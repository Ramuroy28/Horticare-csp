How to run
----------
1. Extract the ZIP file.
2. Open the HortiCare_Final folder in VS Code.
3. Open index.html using Live Server, or double-click index.html.

Included sections
-----------------
Home, About, Main Project (Horticulture), Mini Project (Horticulture Crop Care Guide),
Gallery, and Team & Faculty. There is no Weekly Activities section.
